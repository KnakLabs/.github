# Knak

Knak is the no-code email and landing page creation platform built for enterprise marketing teams. Knak lets marketers design, build, and collaborate on on-brand emails and landing pages without writing code, then sync them to their marketing automation platform.

## Knak Labs

Knak Labs is where the Knak engineering team publishes open-source projects and shows off what we're building.

These repositories are a showcase — a window into how we build:

- **Public and open** — published so anyone can explore how we approach engineering problems.
- **Maintained by Knak** — the code is developed and maintained by Knak employees. These repositories are display-only; we do not accept external forks or pull requests.
- **Curated** — each project reflects work we're proud to share, from internal tools to integrations.

Learn more about Knak at [knak.com](https://knak.com).
